# Aurelvi features

Aurelvi provides local Home Assistant room controls, confirmed entity states, fan/light pages, room inventories, paired switches, covers, clocks and alarms, cameras, weather, a skin catalogue, wallpapers and direct ADB setup.

The website includes enlarged image previews and eight photorealistic digital materials. SIP/WebRTC intercom calls one selected contact at a time, with explicit incoming-call acceptance. It requires a compatible SIP server, phone application and, for locked-phone ringing, provider push support.

European core UI packs are bundled offline. Advanced untranslated descriptions use English. No connection to an earlier panel project or its MQTT namespace is supported.
